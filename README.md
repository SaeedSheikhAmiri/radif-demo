# ردیفه؛ دموی عمومی

نمونهٔ تعاملی با دادهٔ ساختگی برای بررسی رابط و جریان سفارش.

این نسخه فقط در مرورگر اجرا می‌شود. تغییرات در sessionStorage همین تب می‌مانند؛ داده به سرور ارسال نمی‌شود. دستیار با قواعد ساده شبیه‌سازی شده و مدل هوش مصنوعی اجرا نمی‌شود. نسخهٔ اصلی پروژه از Node.js و PostgreSQL و Ollama استفاده می‌کند و در مخزن خصوصی نگهداری می‌شود.

برای امتحان: سفارش جدید → متن نمونه → شبیه‌سازی یا استخراج → بررسی کارت → انتخاب موعد ارسال → تأیید کارت → ثبت آزمایشی. صفحهٔ امروز، مراحل سفارش، رهگیری، مشتری‌ها، محصولات و صندوق پیام‌ها نیز قابل بررسی‌اند. دکمهٔ شروع دوباره نمونه‌ها را بازسازی می‌کند.
